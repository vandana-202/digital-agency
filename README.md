# Digital Agency Website

A responsive digital agency website built with React and Tailwind CSS.

## Features

- Modern Landing Page
- Navbar
- Hero Section
- Services Section
- Portfolio Section
- Testimonials
- FAQ Accordion
- Contact Form Validation
- Admin Dashboard
- Charts
- React Router Navigation
- Responsive Design


## Technologies Used

- React
- Vite
- Tailwind CSS
- React Router DOM
- Recharts
